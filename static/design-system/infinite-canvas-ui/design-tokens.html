Surface静态容器

Canvas、面板、浮层与状态背景；可点击容器改用 Action。

Text / Icon前景内容

正文与独立图标；文字旁图标优先继承 currentColor。

Border边界与选取

表达分隔强度、Focus、选中态和反馈意图。

Action可交互容器

Primary、Secondary、Tertiary 及 Hover、Pressed、Disabled 状态。

选择顺序

先选文字角色，再调整基础值

产品界面优先使用 --ui-text-* 组合样式，它已同时绑定字号、字重、行高与字体。只有组件尺寸、数据可视化或特殊自适应场景，才单独组合 Font Size、Weight、Line Height 等基础 Token。

  1. 确定角色标题、正文、标签、说明或代码
  2. 选择层级同一区域最多保持 3 个清晰层级
  3. 最后例外确有约束时再覆盖单项属性，并记录原因
页面 / 区域标题Title 1–3

按容器层级选择，不按 HTML 标签机械映射。

阅读内容Body / Subtitle

Body 是默认正文；Subtitle 只用于标题后的引导说明。

控件与元数据Label / Caption

Label 用于短标签；Caption 仅承载辅助信息。

机器可读内容Code

Token、路径、快捷键与代码值，不用于普通正文。

底线：不要用字号模拟层级后再叠加任意字重；不要把 Caption 用作长正文；不要用 Letter Spacing 修复中文可读性。正文默认使用 Normal 字距，长文行宽建议控制在 45–75 个字符。
