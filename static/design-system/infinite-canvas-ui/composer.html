组件边界

Composer 负责提示词、参考素材、生成类型、动态参数与提交动作的编排；模型能力和实际生成请求仍由业务页面提供。

公开状态

显示 / 隐藏、图片生成 / 视频生成、无参考 / 有参考、常规 / 展开编辑、浅色 / 深色，以及参数自动换行。

复用基础组件

ic-reference-thumbnail-image、ic-reference-thumbnail-text（Hover 时组合 ic-thumb-hovercard）、ic-prompt-composer、ic-button、ic-icon-button、ic-select 与 ic-generation-settings-picker。
