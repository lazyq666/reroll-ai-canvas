组件顺序

先由 Selector、Slider、Value 表达单个编辑参数，再交给 Dock 组合为业务工具栏。

边界规则

顶部模式栏不属于 Dock；Dock 只管理底部工具、确认操作、滚动与紧凑密度。

响应式

普通模式保持 820px 内的紧凑宽度，宫格模式启用 wide；窄屏仍保留横向滚动。
