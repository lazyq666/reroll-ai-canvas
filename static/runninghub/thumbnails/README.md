# Workflow thumbnail placeholders

The JPEG files in this directory are project-owned geometric placeholders.
They intentionally do not reproduce third-party workflow screenshots or model
output. Existing filenames are retained because provider configuration records
refer to stable workflow IDs.

Each 640×360 image was generated from FFmpeg's `color`, `drawgrid`, and
`drawbox` filters only. No external image input, font, trademark, or generated
model output was used. The placeholders are covered by the repository-level
license.
