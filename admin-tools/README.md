# 管理员工具

此目录只放需要本机管理员主动运行、并提供清晰交互提示的入口。底层实现仍放在
`scripts/`，避免把操作界面和测试逻辑复制成两套。

## 多人协作性能测试（macOS）

双击 `多人协作性能测试-macOS.command`，按提示选择服务端口、管理员账号、Canvas
ID 和测试轮数。默认运行 9 个画布机器人，并由管理员作为第 10 位参与者完成人工
操作。机器人不会发起 AI 生成。测试报告保存在 `/private/tmp/ic-live-acceptance`。

运行前应确保目标 Reroll 服务已经启动且处于 `ready` 状态。

## 抠图并行容量测试（macOS）

双击 `抠图并行容量测试-macOS.command`，即可用固定 2048×1536 输入依次测试并行
1、2、3、4。它直接使用本机 Smart Matting 模型，不需要启动 Web 服务，也不会调用云端
Provider。首次运行若本机没有模型缓存，会按正常抠图流程下载模型。

报告保存在 `/private/tmp/ic-matting-capacity/<时间>/`，同时给出“最高稳定测试档位”和
保留延迟、内存与吞吐余量后的“建议日常并行数”。测试期间 CPU 与内存占用会明显升高。
