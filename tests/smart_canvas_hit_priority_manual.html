画布使用工作区中的真实 JS/CSS。建议按顺序检查：

  1. 从 A → B 连线中部沿线移入 A 右侧“+”，按钮应出现并可点击。
  2. 从“+”快速移回连线：按钮短暂淡出，但连线立即恢复 hover（约 80ms 后按钮消失）。
  3. 在底部 O1 / O2 相邻热区间小幅移动，应稳定；跨过约 8px 后才切换。
  4. 点击 A → B 连线显示剪刀；剪刀应压过“+”并能删除连线。
  5. 点击蓝色 Frame 空白区选中后，再拖动标题栏；Frame 本身应可移动。
  6. 直接拖动任一 Node 的卡片空白位置，连接线应持续跟随。
  7. 打开“+”菜单、键盘聚焦“+”或拖线时，当前热区应保持锁定。
