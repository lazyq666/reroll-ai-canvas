# Infinite Canvas V0：账号系统与画布分享需求文档

> 文档状态：Draft v0.3  
> 创建日期：2026-07-22  
> 适用版本：V0  
> 评审状态：待产品、设计、技术评审

## 1. 背景

当前 Infinite Canvas 默认面向本地单人使用：服务端没有统一账号认证和资源权限校验，画布、API 设置、工作流设置及本地素材均属于同一部署实例下的共享资源。

为了支持小团队内部使用，并让团队成员可以将单张画布安全地分享给外部访客，V0 需要增加：

1. 本地账号登录与固定角色权限。
2. 画布所有者及可见性控制。
3. 单画布只读分享链接。
4. 对 API 设置、工作流设置及画布接口的服务端权限校验。

## 2. V0 目标

### 2.1 产品目标

- 空账号库首次启动时要求用户自行创建管理员账号和密码，普通成员可提交设计师账号申请，由管理员审核后启用。
- 用户必须登录后才能进入正常工作台。
- 系统提供“管理员、设计师、游客”三种固定角色。
- 管理员独占 API 设置和工作流设置权限。
- 管理员和设计师可以共同使用非私有画布。
- 管理员可以把自己拥有的画布设为“仅自己可见”。
- 有画布权限的用户可以生成一条单画布分享链接。
- 未登录访客可以通过有效分享链接查看指定画布，但不能修改数据或调用创作功能。

### 2.2 成功标准

- 未登录用户无法访问工作台、画布列表、任意画布详情及受保护 API。
- 设计师和游客即使绕过前端、直接调用接口，也无法读取或修改 API 设置和工作流设置。
- 分享链接只暴露一张指定画布及其展示所必需的素材。
- 分享访问不会暴露其他画布 ID、画布列表、用户信息、API Key、工作流配置或本地文件目录。
- 分享页面产生的任何操作都不会改变服务端画布状态。

## 3. V0 非目标

以下能力不包含在本期范围内：

- 邮箱验证、邮件通知、找回密码和邀请码。
- OAuth、企业 SSO、LDAP 或第三方账号登录。
- 自定义角色和自定义权限矩阵。
- 按项目、节点或画布局部区域授权。
- 多人同时编辑同一画布的实时协同、光标同步、CRDT/OT。
- 分享链接密码、访问次数限制、访问者名单和访问统计。
- 分享页面评论、批注、复制到自己的空间。
- 多租户组织、计费和用量结算。
- 多后端实例或多 Uvicorn Worker 的分布式会话同步。
- 自定义角色、在线修改角色、登录设备管理和强制下线面板；V0 账号 GUI 只提供申请审批、随机密码重置和删除。

## 4. 角色与身份定义

### 4.1 管理员（Admin）

- 可以登录完整工作台。
- 可以访问所有非私有画布并执行全部画布操作。
- 可以创建、编辑、删除、恢复、彻底删除和分享画布。
- 可以将自己拥有的画布设置为“仅自己可见”。
- 可以访问和修改 API 设置、工作流设置及其他系统级配置。
- 可以查看所有账号，批准或拒绝账号申请，重置随机密码和删除其他账号。
- 首位管理员由用户在首次设置页面创建；额外账号创建、角色修改及账号禁用/启用仍可通过本地 CLI 完成。

### 4.2 设计师（Designer）

- 可以登录工作台。
- V0 内可以访问所有非私有画布，并执行创建、查看、编辑、删除、恢复、彻底删除和分享操作。
- 不能把画布设置为“仅自己可见”。
- 不能查看或修改 API 设置、工作流设置及账号配置。
- 可以在画布中使用管理员已经配置好的 API 和工作流，但不能看到对应密钥或修改配置。

### 4.3 游客账号（Guest）

- V0 保留游客角色，但登录后不获得工作台、画布列表或普通画布访问权限。
- 只能通过有效的画布分享链接进入对应画布的只读页面。
- 游客账号在 V0 中与匿名分享访客的资源权限相同；保留该角色是为了后续扩展实名访客、评论或访问记录。

### 4.4 匿名访客（Anonymous）

- 未登录且没有分享链接时没有任何业务权限。
- 持有有效分享链接时，仅获得该分享链接对应画布的只读访问权限。
- 分享链接是临时授权凭证，不代表系统账号。

## 5. 权限总则

1. 所有权限必须在服务端校验，不能只依赖隐藏菜单或禁用按钮。
2. 权限采用“默认拒绝”：未明确允许的接口和资源访问一律拒绝。
3. 分享 Token 只能授权一张画布，不能转换为正常登录 Session。
4. “仅自己可见”是画布级最高优先级规则，高于管理员和设计师的全局画布权限。
5. 管理员只能将自己拥有的画布设置为“仅自己可见”。
6. V0 默认私有画布不可分享；启用“仅自己可见”时必须立即撤销该画布已有的分享链接。
7. V0 中设计师的“所有画布 100% 权限”指所有非私有画布。
8. 分享页面允许平移、缩放、查看大图和播放媒体等纯浏览交互，但不能进行会修改服务端状态的操作。

## 7. 功能需求

### 7.1 账号申请与管理

#### FR-AUTH-001：小团队账号申请

- 登录页提供简单账号申请，输入登录账号、可选显示名称和密码即可提交。
- 账号申请的角色必须由服务端固定为 `designer`，请求不能指定或提升角色。
- 提交成功后状态为 `pending`，不创建账号或 Session；管理员批准后才创建 `active` 账号。
- 默认最多允许 10 个“启用账号 + 待审核申请”；达到上限后停止接受新申请。
- 被拒绝的申请可以使用同一用户名和新密码重新提交。
- 部署者可通过环境变量关闭账号申请或调整账号上限。
- 未配置账号时，服务不得以无鉴权模式自动开放工作台。
- 认证数据库中没有任何账号时，服务首次启动必须自动创建账号和密码均为 `admin` 的启用管理员；已有任何账号时不得新增、覆盖或重置该账号。

#### FR-AUTH-002：管理员账号管理

- 本地账号至少包含：唯一 ID、用户名、密码哈希、角色、状态、创建时间、更新时间。
- 用户名在当前部署实例内唯一。
- 角色只能是 `admin`、`designer`、`guest`。
- 状态至少支持 `active` 和 `disabled`。
- 管理员 GUI 必须列出全部账号及待审核、已拒绝申请。
- 管理员可以直接批准或拒绝待审核申请；批准后账号角色固定为设计师。
- 管理员可以把指定账号密码重置为密码学安全的随机临时密码；明文只在响应和界面中显示一次，重置后撤销该账号全部 Session。
- 管理员可以删除其他账号，但不能删除当前登录账号或最后一个启用管理员。
- 删除账号时，其画布转交给执行删除的管理员，已有分享链接撤销，画布内容不得删除。
- 管理员、游客创建、账号禁用/启用和角色修改继续支持服务器本地 CLI。
- 管理操作和账号申请均应立即生效，不要求重启服务。

#### FR-AUTH-003：登录与退出

- 用户使用用户名和密码登录。
- 登录成功后创建服务端可校验的 Session，并使用安全 Cookie 保存 Session 标识。
- 登录失败统一返回“用户名或密码错误”，不得泄露账号是否存在。
- 被禁用账号不能创建新 Session；已有 Session 应在合理时间内失效，或由管理员主动撤销。
- 用户可以主动退出，退出后当前 Session 立即失效。

#### FR-AUTH-004：当前用户信息

- 前端可以读取当前登录用户的 ID、显示名、角色和账号状态。
- 接口不得返回密码哈希、Session Secret 或其他用户的敏感信息。

### 7.2 服务端鉴权与权限校验

#### FR-AUTHZ-001：统一请求身份

- 除登录接口、分享页面和分享只读数据接口外，所有业务接口默认要求登录。
- 服务端必须从 Session 获取用户身份，不能信任客户端传入的 `user_id`、角色或所有者字段。
- WebSocket 连接也必须校验登录 Session；分享页面 V0 不建立可写 WebSocket 连接。

#### FR-AUTHZ-002：管理员专属设置

- API 设置和工作流设置的页面入口仅管理员可见。
- API 设置和工作流设置的所有读取、创建、修改、删除、测试连接、导入和导出接口仅管理员可调用。
- 设计师和游客直接请求相关页面时进入 403 页面或返回工作台首页。
- 设计师和游客直接请求相关 API 时返回 HTTP 403。
- API Key 不得通过任意普通配置接口原文返回；管理员界面也只显示掩码，更新时采用“留空即不修改”。

#### FR-AUTHZ-003：分享访问隔离

- 分享访问使用独立的只读接口集合，不复用需要完整账号权限的画布保存接口。
- 分享接口只能返回渲染指定画布所必需的数据。
- 分享访问不得访问画布列表、回收站、项目列表、历史记录、生成任务、素材库管理、API 配置或工作流配置。

### 7.3 画布所有权与可见性

#### FR-CANVAS-001：画布所有者

- 新建画布时，服务端把当前登录用户记录为 `owner_id`。
- 客户端不能直接修改 `owner_id`。
- 现有历史画布在首次升级时统一归属首个管理员账号，并记录迁移结果。

#### FR-CANVAS-002：画布可见性

- 画布至少支持两种可见性：
  - `shared`：实例内管理员和设计师可访问。
  - `private`：仅画布所有者本人可访问。
- 新建画布默认可见性为 `shared`。
- 只有管理员可以把自己拥有的画布在 `shared` 和 `private` 之间切换。
- 用户无权访问私有画布时，服务端应返回 404，避免泄露画布是否存在。

#### FR-CANVAS-003：私有画布与分享互斥

- 私有画布不能创建分享链接。
- 画布从 `shared` 改为 `private` 时，服务端必须在同一业务操作中撤销其全部有效分享链接。
- 已撤销链接再次打开时返回统一的失效页面，不泄露画布标题和所有者。

### 7.4 画布分享链接

#### FR-SHARE-001：创建分享链接

- 管理员和设计师可以在自己有权访问的非私有画布上点击“分享”。
- 分享弹窗至少提供：开启分享、复制链接、关闭分享。
- 分享 URL 不得直接使用可枚举的画布 ID 作为授权凭证，推荐格式：`/share/{share_token}`。
- `share_token` 必须由密码学安全随机数生成，至少具有 128 bit 随机强度。
- 同一画布 V0 默认只保留一条有效分享链接；再次启用时可复用现有有效链接，选择“重新生成”后旧链接立即失效。

#### FR-SHARE-002：关闭和撤销分享

- 有画布权限的管理员或设计师可以关闭分享。
- 关闭分享后，旧链接立即失效。
- 删除画布、将画布移入回收站、彻底删除画布或设为私有时，相关分享链接立即失效。

#### FR-SHARE-003：分享页面

- 分享链接打开后进入独立的单画布页面，不显示工作台导航、画布列表、设置菜单和编辑工具栏。
- 页面可以展示画布标题、节点、连接、文本、图片、视频、音频及其他只读渲染内容。
- 允许的纯浏览行为包括：平移、缩放、初次自动适配、minimap 导航、图片预览、视频和音频播放。
- 禁止编辑节点、移动节点、创建或删除连接、修改标题、上传、生成、重新运行、保存、删除、恢复、导出、下载原始素材和复制到工作台。
- 不得加载正常编辑页面中仅创作功能需要的 API Key、模型列表或工作流详情。
- 分享页面应增加 `noindex, nofollow`，避免被搜索引擎主动收录。

#### FR-SHARE-004：分享素材访问

- 分享页面只能访问当前画布实际引用的媒体资源。
- 分享 Token 不得授权任意 `/assets/`、`/output/` 或本地存储路径遍历。
- 服务端应通过分享专用媒体接口校验“Token 有效 + 素材确实被该画布引用”。
- 分享响应不得返回服务器绝对路径。
- V0 不提供防截图能力；应在产品说明中明确网页内容无法阻止系统截图或浏览器层面的缓存。

### 7.5 游客行为

#### FR-GUEST-001：无分享链接访问

- 匿名用户访问工作台、画布列表或普通画布 URL 时，跳转到登录页。
- 已登录游客访问上述资源时显示“当前账号无可访问内容”，不展示画布元数据。

#### FR-GUEST-002：持分享链接访问

- 匿名用户和游客账号均可打开有效分享链接。
- 登录状态不会扩大分享 Token 的权限；游客和匿名用户均保持单画布只读。
- 分享 Token 失效、画布被删除或画布变为私有时，显示统一的“链接无效或已失效”页面。

## 8. 页面与交互范围

### 8.1 登录页

- 提供“登录”和“创建账号”两个模式。
- 登录模式包含账号、密码、登录按钮和错误提示。
- 登录模式提供可选的“记住密码”；只在登录成功后保存到当前浏览器本地，取消勾选时立即清除，不建议在共享设备启用。
- 注册模式包含账号、显示名称、密码和确认密码，并明确提示“申请角色为设计师、需要管理员审核”。
- 达到账号上限或关闭注册时，禁用或隐藏注册入口。
- V0 不提供“忘记密码”入口。

### 8.2 账号状态区

- 工作台显示当前用户名和角色。
- 支持退出登录。
- 设计师和游客看不到账号管理、API 设置和工作流设置入口。

### 8.3 管理员账号管理页

- 仅管理员可见并可访问。
- 分区显示账号申请和全部账号，标明角色、状态和当前账号。
- 待审核申请提供“通过”和“拒绝”；账号提供“重置密码”和“删除”。
- 随机临时密码必须在独立确认框中显示并支持复制，关闭后前端清空明文。
- 删除前明确提示画布转交和分享失效；当前账号的删除操作禁用。

### 8.4 画布列表

- 管理员和设计师只能看到自己有权访问的画布。
- 私有画布显示明确的私有标识，仅所有者可见。
- 分享中的画布显示分享状态标识。
- 画布菜单增加“分享”和“可见性”入口；“可见性”仅符合条件的管理员可见。

### 8.5 分享弹窗

- 当前分享状态。
- 分享链接只读输入框。
- 复制链接按钮。
- 开启或关闭分享按钮。
- 重新生成链接按钮。
- 私有画布中分享入口禁用，并提示“仅自己可见的画布不能分享”。

### 8.6 分享查看页

- 独立路由和精简布局。
- 只展示单张画布。
- 提供必要的缩放、平移和媒体预览控件。
- 右下角提供与智能画布一致的 minimap；初次自动适配但不显示单独的“适应画布”按钮。
- 顶部只保留画布标题和“只读”状态，不增加独立说明文案模块。
- 不展示任何写操作、生成按钮、设置入口或其他画布导航。
- 失效链接使用统一错误页。

## 10. 建议 API 契约

### 10.1 认证

- `POST /api/auth/login`：用户名和密码登录。
- `POST /api/auth/logout`：撤销当前 Session。
- `GET /api/auth/me`：返回当前用户的公开身份信息。
- `GET /api/auth/registration`：返回申请开关和剩余容量。
- `POST /api/auth/register`：提交待审核设计师账号申请，不创建 Session。

### 10.2 管理员账号管理

- `GET /api/admin/accounts`：列出账号、申请和容量。
- `POST /api/admin/account-applications/{id}/approve`：批准申请。
- `POST /api/admin/account-applications/{id}/reject`：拒绝申请。
- `POST /api/admin/accounts/{id}/reset-password`：生成并返回一次性随机临时密码。
- `DELETE /api/admin/accounts/{id}`：删除账号、撤销分享并转交其画布。

### 10.3 画布权限

- `PATCH /api/canvases/{canvas_id}/visibility`：管理员修改自己画布的可见性。
- 现有画布列表、读取、保存、删除、恢复和彻底删除接口统一增加 Session 和画布权限校验。
- 所有画布写接口由服务端写入 `updated_by`，忽略客户端提交的同名字段。

### 10.4 分享

- `POST /api/canvases/{canvas_id}/share`：开启分享或返回现有有效分享链接。
- `POST /api/canvases/{canvas_id}/share/regenerate`：重新生成链接并撤销旧链接。
- `DELETE /api/canvases/{canvas_id}/share`：关闭分享。
- `GET /api/canvases/{canvas_id}/share`：查询分享状态，不返回历史明文 Token。
- `GET /api/shares/{share_token}`：获取分享页面所需的单画布只读数据。
- `GET /api/shares/{share_token}/media/{media_id}`：访问经画布引用校验的分享媒体。

### 10.5 返回状态

- `401 Unauthorized`：未登录或 Session 失效。
- `403 Forbidden`：身份有效，但无操作权限。
- `404 Not Found`：资源不存在，或为避免泄露而隐藏无权访问的私有资源。
- `409 Conflict`：画布版本冲突或可见性、分享状态冲突。
- `429 Too Many Requests`：登录尝试或分享访问触发限流。

## 11. 安全要求

### SEC-001：密码与 Session

- 密码必须使用带独立随机盐和高迭代成本的密码派生算法；当前实现使用 PBKDF2-SHA256（600,000 次），禁止明文和普通 SHA 哈希。
- Session Token 必须使用密码学安全随机数生成。
- Cookie 至少设置 `HttpOnly`、`SameSite=Lax`；HTTPS 部署时必须设置 `Secure`。
- 修改密码、禁用账号后应支持撤销该账号全部 Session。

### SEC-002：登录保护

- 按账号和来源 IP 限制连续登录失败次数。
- 登录日志不得记录密码。
- 错误响应不得区分“账号不存在”和“密码错误”。

### SEC-003：CSRF 与跨域

- Cookie Session 下的写接口必须具备 CSRF 防护。
- 生产模式不得继续使用任意来源 CORS；只允许明确配置的站点来源。

### SEC-004：敏感配置

- 非管理员不得读取、修改、测试或清空 API Key。
- 任何角色都不应通过 API 获取 API Key 明文；管理员只查看掩码。
- 分享页面不得请求 `/api/config/token`、完整 Provider 配置或工作流管理接口。

### SEC-005：分享 Token

- 数据库存储 Token 哈希，服务端只在创建或重新生成时返回一次完整 URL。
- Token 不应出现在常规应用日志、错误追踪上下文或页面分析参数中。
- 分享页面设置合理的 `Referrer-Policy`，避免 Token 随 Referer 泄露到第三方站点。

## 12. 非功能要求

### 12.1 性能与稳定性

- V0 目标规模：单实例、10 名团队成员、单 Uvicorn Worker。
- 10 名已登录用户分别编辑不同画布并持续自动保存 10 分钟时，不出现 JSON 损坏、异常 5xx 或跨画布数据串写。
- 10 个分享访客同时打开不同或相同分享链接时，权限结果一致且不泄露其他画布。
- 轻量接口在目标部署设备上的 P95 响应时间目标为 500ms 以内；大媒体加载和外部生成 API 不计入该指标。
- 账号、Session 和分享状态在服务重启后必须保留。

### 12.2 兼容与迁移

- 升级前自动备份账号数据和画布权限元数据。
- 所有历史画布必须迁移到明确的 `owner_id` 和 `visibility`，不得保留空权限状态。
- 迁移失败时停止以多人模式启动，避免自动退回无鉴权模式。
- V0 不承诺多个服务进程共同读写同一份本地数据。

### 12.3 可观测性

- 至少记录登录成功、登录失败、退出、账号禁用、角色变更、创建分享、重新生成分享、撤销分享和私有化画布事件。
- 日志记录操作者 ID、目标资源 ID、时间和结果，但不得记录密码、Session Token、分享 Token 或 API Key。

## 13. 验收标准

### AC-01：受限账号申请与审批

- 普通用户可在登录页提交申请，申请角色固定为设计师且不能直接登录。
- 伪造 `admin` 或 `guest` 角色的注册请求不能改变服务端固定角色。
- 管理员可以查看、批准或拒绝申请；批准后申请人使用原申请密码登录。
- 默认“启用账号 + 待审核申请”达到 10 个后，新申请被拒绝。
- 空账号库首次启动必须完成管理员账号与工作区目录设置，系统不得生成或接受内置默认凭据；重复初始化必须被拒绝。

### AC-01A：账号管理操作

- 管理员可重置其他账号密码并只获得一次随机临时密码；旧密码和已有 Session 立即失效。
- 管理员可删除其他账号，但不能删除自己或最后一个启用管理员。
- 删除后账号不能登录，其画布归执行删除的管理员，分享链接失效。
- 设计师直接访问账号管理页面或 API 时返回首页或 403。

### AC-02：未登录隔离

- 未登录用户访问工作台、画布列表或已知画布 ID 时无法获得画布数据。
- 未登录用户直接调用画布、素材、历史、配置和工作流接口时返回 401 或用于资源隐藏的 404。

### AC-03：管理员权限

- 管理员可以完成 API 设置、工作流设置及所有非私有画布操作。
- 管理员可以将自己拥有的画布设为私有并恢复为内部可见。

### AC-04：设计师权限

- 设计师可以创建和完整操作非私有画布。
- 设计师看不到 API 设置和工作流设置入口。
- 设计师直接调用相关设置接口时服务端返回 403，且配置不发生变化。

### AC-05：游客权限

- 游客登录后看不到画布列表和普通画布内容。
- 游客只能通过有效分享链接读取指定画布。

### AC-06：私有画布

- 私有画布只对其所有者可见。
- 画布列表、画布 ID 直访、搜索或其他接口均不会向其他用户泄露其标题和元数据。
- 私有化操作会立即撤销已有分享链接。

### AC-07：分享创建与撤销

- 管理员或设计师可以为非私有画布开启分享并复制链接。
- 撤销、重新生成、删除画布、移入回收站或私有化后，旧链接立即失效。

### AC-08：分享页面只读

- 匿名访客通过有效链接只看到指定画布。
- 访客可以平移、缩放、预览图片和播放媒体。
- 页面没有编辑、生成、保存、删除、下载、导出和设置入口。
- 访客构造画布写请求时服务端返回 401/403，画布版本和内容保持不变。

### AC-09：分享素材隔离

- 分享访客只能读取当前画布实际引用的媒体。
- 修改媒体 ID、文件名或路径后无法读取未被该画布引用的文件。
- 响应中不包含服务器绝对路径。

### AC-10：敏感配置保护

- 设计师、游客、匿名用户和分享访客均不能获得 API Key 明文。
- 现有可能返回 Token 的接口完成权限收口或移除明文返回能力。

### AC-11：服务端强制执行

- 所有权限验收均包含“隐藏前端入口”和“手工直接调用 API”两种测试。
- 修改客户端角色、`owner_id`、`visibility` 或请求头不能提升权限。

### AC-12：历史数据迁移

- 升级后所有历史画布归属首个管理员，默认 `shared`。
- 迁移过程可重复执行且不会重复创建用户、分享记录或破坏画布内容。

## 14. 建议实施顺序

1. 建立 User、Session、AccountApplication、本地管理员创建、申请审批和登录/退出能力。
2. 给全部现有接口增加默认鉴权，并先保护敏感配置接口。
3. 增加角色校验，收口 API 设置和工作流设置。
4. 增加画布 `owner_id`、`visibility` 及历史数据迁移。
5. 对画布列表、读取、保存、删除、恢复等接口增加资源级权限。
6. 增加分享记录、Token 和分享管理接口。
7. 开发独立的只读分享页面和分享专用媒体接口。
8. 完成权限绕过测试、迁移测试、10 人基础并发测试和发布前安全检查。

## 15. 待确认问题与 V0 默认决策

以下问题不阻塞初版设计；如果产品未另行确认，V0 按“默认决策”执行。

| 问题 | V0 默认决策 |
|---|---|
| 多个管理员能否查看另一个管理员的私有画布？ | 不能；“仅自己可见”优先于管理员全局权限 |
| 私有画布能否通过秘密链接分享？ | 不能；私有化会撤销全部分享链接 |
| 设计师是否可以删除所有非私有画布？ | 可以，按“V0 所有画布 100% 权限”执行 |
| 设计师是否可以修改画布所有者？ | 不能；V0 不提供所有者转移 |
| 游客账号登录后是否拥有额外能力？ | 没有；V0 与匿名分享访客权限一致 |
| 分享访客是否可以下载原图或导出画布？ | 不能；仅允许页面内浏览和媒体播放 |
| 分享链接是否设置过期时间或密码？ | V0 不支持；只支持主动撤销和重新生成 |
| 是否开发账号管理后台？ | 开发精简 GUI：查看、通过/拒绝申请、随机密码重置、删除；角色和启停仍由 CLI 管理 |
| 是否支持两人同时编辑同一画布？ | 不作为 V0 验收目标；后续版本单独设计协同编辑 |
| 是否直接增加多个后端 Worker？ | 不增加；完成数据库、共享 Session、任务队列和消息总线后再评估 |
