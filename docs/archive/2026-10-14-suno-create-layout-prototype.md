## 问题与范围

将 Reroll 已有 Suno 音乐功能放进 Suno Create 的空间结构，评估能否在同一屏中完成输入、生成、试听和参数复用。用户明确指定这一布局，因此只提供一个完整方案。

原型位于 `static/music-create-prototype.html`，使用独立 JS/CSS 和共享中英文资源。复用既有首页侧栏，仅改创作音乐与工作区的预览内容；保留正式方案 B 和历史原型入口，不接入正式生成或写入接口，不改变 Workspace、Provider 或 Generation Run 的责任。

## Chrome 观察

直接在已登录的 [Suno Create](https://suno.com/create) 查看并操作简单 / 详细模式、More Options 和歌曲更多操作；没有生成音乐、上传文件或导出账号内容。

## 可评审行为

运行：

```sh
npm run prototype:music-create
```

打开 [带现有侧栏的本地 Demo](http://127.0.0.1:18886/?prototype=music&variant=B)。服务器仅监听 `127.0.0.1:18886`；必须以 `--create` 启动，若旧预览服务占用端口需先停止。此模式只在预览服务器内将原壳的 lab iframe 响应映射到新内容，不更改 `studio-shell.js`、侧栏样式或正式页面路由；不带 `--create` 的历史原型仍按原行为运行。也可直接打开 `/static/music-create-prototype.html` 单独评审内容。

- 初始八首示例可试听。音频是本地原创合成的 12 秒 WAV；所有曲目使用同一段示例，不表示模型生成质量。封面时长与实际试听一致。
- 点击创作后右侧显示两个等待条目，约两秒后出现两个版本；桌面创作区保持可见，窄屏切到曲库。每首结果保存提交时的完整草稿及参考，后续编辑不改写结果参数。
- 人声歌曲 / 纯音乐、自动写词 / 自填歌词、v6 / v6-mini / v6-wild、风格、排除风格、人声、变化程度、格式、Max、时长、三类权重和已有 Persona ID 均可交互。
- 音频选择和拖入保留在本机，不上传。支持 MP3 / WAV / M4A / AAC / OGG / FLAC，每首最多 50 MiB，最多四首；可通过“使用示例音频”体验参考流程。
- Cover 接受一首可读取且短于 480 秒的参考；允许人声或纯音乐。Inspire 允许最多四首参考，禁用时长和 Persona；开启纯音乐时保留草稿并阻止生成，提示切换 Cover。切换操作不静默删除参考。
- 视图、筛选、生成结果和草稿都在内存中；刷新清空。收藏/收藏筛选及跨全部历史的最早排序置灰，使用控件说明和行内短句解释原因。嵌入时语言和主题跟随原有侧栏控制，独立打开时使用创作标题栏内的预览控制；主题统一通过既有 theme.js 与 data-ui-theme 处理并沿用共享偏好。
- 下载 WAV 提供真实示例文件；MP3 / M4A 的格式准备按钮在 Demo 中置灰，明确说明正式功能已支持而此 Demo 未连接。
- 详情、扩大内容编辑、参考和人设使用键盘可关闭的模态窗口。颜色、Focus 与浮层阴影消费 Reroll 共享 Token；模型版本复用公共 `ic-select` 的 Small 次级变体，其余原生控件保留用于评估指定布局，后续正式实现继续迁移公共组件。
- 内容区 700px 以下仅显示创作 / 曲库切换，底部播放器保留；不再创建或控制任何侧栏。
- 曲库标题只保留“我的工作区”，移除“工作区 >”前缀以及“能力说明”入口和弹窗。能力核查保留在本说明中。Persona 入口为 Persona ID；弹窗允许填写已有 ID，将创建声线 / Persona 置灰。

## Reroll 配色适配（2026-10-14）

入口在页面样式之前加载 `static/css/design-tokens.css`，并使用既有 `static/js/theme.js`。删除原型自建的两套颜色和 `data-theme` 适配；页面直接消费公共语义颜色，不修改公共 Token、侧栏或生产工作台。

- 页面背景使用 `surface-subtle`，表单卡片与播放器使用 `surface`，弹层使用 `surface` / `surface-floating`。
- 主按钮使用 `action-primary` / `text-on-action-primary`，浅色黑底白字、深色白底黑字，移除原桃橙色。
- 次级动作、悬停、选中与禁用分别使用对应 `action-*`；分段控件选中背景使用 `surface-segmented`。禁用颜色直接来自语义 Token，不再给整个控件叠加透明度。
- 正文、次级说明、元信息、Placeholder 与错误分别使用 `text-primary`、`text-secondary`、`text-tertiary`、`text-placeholder` 与 `text-danger`；配对图标继承文字色，禁用图标使用 `icon-disabled`。
- Border、Focus、播放器进度、媒体 Mask、模态 Backdrop 与弹层 Shadow 同步使用公共角色。封面插画保留示例素材自身的颜色，不参与界面色板。

验收包含真实外壳下的 Light / Dark、主动作前景/背景配对、禁用/选中/错误与键盘 Focus、英文窄屏及禁用说明。`tests.test_design_tokens_ui` 的入口清单纳入本 Demo，核对 Token 在页面 CSS 之前加载、UI scope 与所用语义颜色均有效。

## 模型选择器复用（2026-10-14）

原生模型下拉使用页面私有的固定宽度、24px 圆角和 Padding，表现为与组件库不一致的大胶囊。替换为 `ic-select` 的 Small 次级变体（secondary、small、bottom-end），通过公共 `core.js` 加载，复用 32px 小圆角触发器、音频图标、展开图标、等宽菜单、键盘交互和主题状态。页面仅给 Host 分配 128px 布局宽度，移除 `.version-select` 的私有圆角、Padding、颜色和字形样式；恢复页面根字号的默认尺寸，把原型正文 13px 字号下放到 body，避免缩小公共组件的 rem 尺寸。

选择结果写入创作草稿，切换简单/详细、语言、重绘与沿用设置均从草稿恢复。模型名称与可访问名称继续使用共享中英文资源。浏览器验收以本页面为准：三个模型可选择、长名称完整、菜单选择后关闭、方向键/Enter 可选择、Escape 关闭、模式和语言切换保留选择、390px 无横向溢出、Light/Dark 均使用公共样式。此次只替换原型的模型选择器，不改公共组件实现。
