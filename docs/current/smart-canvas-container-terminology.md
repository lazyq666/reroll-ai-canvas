# Smart Canvas 编组与分区命名

> Status: Current  
> Source: GitHub Issue #167
> Scope: Smart Canvas 中文界面、帮助文案、组件样板与领域词汇

## 1. 用户可见名称

| 内部领域名 | 中文界面名称 | 含义 |
| --- | --- | --- |
| Smart Group | 编组 | 显式拥有一组有序 Node 或媒体成员，可作为整体整理、预览、下载或参与生成 |
| Frame | 分区 | 按空间包含关系组织 Node 的带标题区域，不拥有其中内容 |

`Smart Group`、`Frame`、`smart-group` 和 `smart-frame` 继续作为英文领域名、代码类型与持久化类型。此次命名调整不改变数据结构、成员关系、空间关系、权限、协作协议或生成行为。

## 2. 操作语言

Smart Group 的中文操作统一使用“编组”：

- 创建编组、移入编组、移出编组、整理编组、运行编组、解散编组；
- 编组操作、编组内图片、编组内没有可整理的节点。

Frame 的中文操作统一使用“分区”：

- 创建分区、绘制分区、重命名分区、切换分区颜色；
- 取消分区并保留其中节点；
- 删除分区及其中内容。

“画布”只表示完整 Canvas，不再作为 Frame 的中文名称。“分组”可以继续用于提示词模板分类等其他普通分类场景，但不再作为 Smart Group 的产品名称。

## 3. 默认标题与旧内容

- 新 Smart Group 的默认标题是“编组”。
- 新 Frame 的默认标题按“分区 1”“分区 2”递增。
- 旧内容中的默认标题“万能分组”“智能分组”“Smart Group”“画布 / 画布 N”与“Frame / Frame N”在载入时按当前界面语言显示为对应的新名称。
- 用户自定义标题不因本次命名调整而改变。

## 4. 验收

1. 创建菜单、工具栏、快捷键说明、空状态、上下文菜单、Toast、默认标题和组件样板使用“编组 / 分区”。
2. 中文界面不把 Smart Group 显示为“智能分组”，也不把 Frame 显示为“画布”或“画布框”。
3. 解散编组与取消分区使用不同动词，且取消分区明确保留其中节点。
4. 英文界面和内部类型保持不变。
5. 旧默认标题能够兼容显示为新名称，自定义标题保持原样。
