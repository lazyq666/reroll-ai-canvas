# Canvas 列表浏览

- 关联任务：LAZ-136
- 状态：Implemented；本地验证完成，用户视觉与交互验收待完成
- 页面：`/static/canvas-list.html`，包含 App Shell 内嵌入口

## 目标与边界

将画布列表从可拖动、平移和缩放的空间看板改为常规滚动列表，方便寻找、创建和管理 Canvas。用户指定的 RunningHub 项目页用于参考布局、分类、搜索、排序、回收站与功能入口；Reroll 继续使用自己的组件、主题和权限模型。

Project 是已有的分类与访问授权边界，不新增文件夹层级，不将 Canvas 改名为 Project 或 Scene。列表不创建新权限，不改动 Smart Canvas 编辑器的平移、缩放或节点操作。旧 `board_x` / `board_y` 保留用于数据兼容，列表不读取或写入这些坐标。

## 页面与操作

- 左侧保留可访问 Project 导航，新增项目名称搜索。管理员保留新建、重命名、删除项目操作；设计师不获得管理入口。
- 右侧显示当前 Project 名称。顶部有回收站、刷新、新建画布以及有剪切内容时的粘贴入口。
- 分类为「全部画布 / 共享 / 我的」。「共享」按 Canvas Visibility 筛选；「我的」按 `created_by` 与当前登录账号匹配，包含自己创建且仍有权访问的共享和私有画布，不按当前所有者或最后编辑者判断。创建者缺失的记录不推断归属；历史迁移已补为初始管理员的记录沿用已有归属。
- 分类入口使用中号 `ic-segmented-control`，以整体底板和选中项表面提高网点背景下的辨识度；沿用公共组件的单选语义、方向键切换及明暗主题。
- 搜索画布名称，按最近修改、创建时间或名称排序，分别支持升序和降序。默认最近修改、降序；已有置顶记录仍排在最前。
- 卡片采用自适应封面网格、正常纵向滚动、固定字号。宽屏默认每行六张，较窄窗口逐级减少列数；节点数与时间使用三级文字色。背景保留公共 `ic-canvas-grid` 网点，仅作装饰，不接管滚动和点击。点击或 Enter 打开画布；更多菜单保留重命名、分享、可见性、导出、移动和删除等原有能力。保留在线协作者，卡片不显示「可编辑」和「仅自己」标签。
- 新建画布后清空搜索与分类筛选，恢复最近修改降序，便于看到新内容。
- 回收站继续提供恢复、管理员永久删除和原有确认流程；30 天保留规则不变。
- 跨项目移动入口统一称为「迁移画布」（英文 Move canvas）：选中后切换到目标项目，点击「迁移到此项目」完成；提示文案与菜单使用同一术语。
- 窄窗口将项目导航移至顶部并限制高度，搜索和排序换行，不缩放卡片文字。中英文和明暗主题使用共享 i18n 与 Design Tokens。

## 查询与数据

`GET /api/canvases` 在既有 `project`、`cursor`、`limit` 上增加可选参数：

| 参数 | 值与默认值 |
| --- | --- |
| `search` | 名称包含匹配；去除首尾空格，Unicode casefold；默认空 |
| `visibility` | `shared` / `private`；空或其他值不额外筛选 |
| `mine` | 布尔值，默认 `false`；为 `true` 时服务端按当前认证账号过滤 `created_by`，不接受客户端指定另一位创建者 |
| `sort` | `updated`（默认）/ `created` / `title`；其他值按更新时间 |
| `direction` | `asc` / `desc`（默认）；其他值按降序 |

先检查角色、项目和私有权限，再过滤、排序、分页。筛选影响的是完整授权结果，不仅是前端已加载的 40 条。结果总数属于当前查询，左侧项目数量仍是项目总数。服务端拥有筛选与排序规则，前端不再次用另一套文本规则筛选。

搜索或排序变化时清空分页缓存，从第一页重新读取；旧请求不能覆盖新筛选或新项目。重置查询期间禁用加载更多。索引重建继续采用有界解析，未完成时显示继续建立列表入口，不声称没有结果；重建结束后重置合并窗口，避免把临时顺序混入稳定分页。

## 状态与恢复

加载、无画布、无匹配结果、无项目权限和读取失败互斥。无匹配结果提供清除筛选；加载失败提供现有刷新入口，不能误报无权限或诱导创建替代画布。项目名称搜索无匹配时在导航区独立提示，不改变当前项目。

LAZ-137：首次读取、刷新和重置查询等待期间使用与正式网格相同列数的十二张卡片骨架，封面保持 16:9，名称与元信息使用公共 `ic-skeleton` 文本占位。骨架不显示额外加载文案或操作入口；区域使用中英文可访问名称，旧卡片隐藏并退出键盘与 Pointer 交互。成功、空结果与失败后移除骨架，继续使用既有结果及恢复状态。追加分页保持现有卡片和按钮加载反馈；Reduced Motion 使用公共骨架的静态反馈。

## 验收

- 查询：跨首屏匹配、分页前排序、升降序、创建者过滤、私有与项目隔离、置顶稳定性；「我的」不等同于私有或当前所有权。
- 交互：项目搜索、分类、排序、清除筛选、分页、滚动、打开画布、新建入口、菜单、回收站。
- 稳定性：旧搜索响应不会覆盖新结果，刷新期间不能追加分页，加载失败可刷新恢复，浏览列表不写入位置。
