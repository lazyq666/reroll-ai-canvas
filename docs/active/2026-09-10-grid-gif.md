# 完整角色与特效归组后合成 GIF

> Status: Implemented — 本地验收通过，Review，未发布  
> Tracked by: [Issue #91](https://github.com/lazyq666/reroll-ai-canvas/issues/91)  
> Feature: F10

## 目标与范围

可编辑 Smart Canvas 的 Designer 从图片节点浮动菜单进入「合成 GIF」，复用 Large `ic-ai-processor-dialog` 的 `grid-gif` 变体，标题为「图片处理」。从透明精灵图提取完整角色，自动放置归属边界，将独立特效归组后输出循环 GIF。视频、音频和智能分层节点没有此入口。

不调用 Provider，不修改原图，不自动去除不透明背景，不推断剑气的语义走势；不提供帧重排和逐帧时长。当前操作不会保存为原图的持久编辑草稿。

## 识别与归组

「素材排列」沿用 1×2、2×1、2×2、2×3、3×2、3×3，并提供默认 4×4 和自定义 1–12 行列，至少 2 帧。排列用于定位每格中下部的身体和确定帧序，绝不作为角色裁剪边界。

使用原图透明通道的八邻域连通关系识别完整组件。Alpha 大于 8 的像素作为识别核心，随后恢复与核心相连的淡色边缘，避免近乎透明的杂点把两个角色连接起来。完全孤立且 Alpha 不超过 8 的杂点不作为素材。身体由排列中的中下部像素占比定位，不按全图最大组件排行；相连的武器、披风和剑气保留在同一帧。

剩余组件作为独立特效：根据组件像素落在归属区域内的多数票分配整块组件，平票由组件中心所在区域决定，不按与角色的距离分配，也不切断碎片。不同角色的包围框可以重叠；实际输出按像素归属蒙版复制，不能把邻近角色复制进同一帧。

默认自动沿透明间隙放置横向和纵向归属折线：完整角色的像素提供边界两侧约束，独立特效像素与小范围留白参与避让成本，连续路径避免穿过剑气中的微小间隙。搜索在相邻排列中心之间进行，优先避让角色，再减少穿过特效；这不是按最近角色分配，也不代表理解特效语义。

横向边界可绕开伸入上一行的剑尖，纵向边界可绕开伸入相邻列的披风与剑气。自动折线经过保留避让约束的简化，控制点数量随轮廓变化。左侧显示帧号、归属折线与独立碎片彩框；可拖动横、竖折线控制点继续修正。折线可越过原宫格，但同向边界不能相互交叉。右侧不提供调整点下拉框或坐标输入。仅通过鼠标点击选中、拖动控制点调整；不提供控制点键盘快捷键，也不显示边界／对齐操作提示段落。不到 4 个核心像素的碎片仍参与输出，但不绘制彩框。

行列变化会重置边界和对齐点；颜色、透明背景、速度及语言切换保留人工调整。「重新自动分组与对齐」清除本次人工调整，并重新计算边界和身体／脚底基准。拖动结束后重新识别归属；过期识别请求会取消。

## 对齐与输出

「角色对齐」为每帧提供十字基准：横向位置表示身体中心，纵向位置表示脚底。初始值由角色下部和脚底像素估计，不使用包含特效的整体包围框中心；特殊姿势允许在画面上用鼠标拖动修正。

每帧把该基准移动到公共位置，特效保持相对角色的原始偏移。公共画布尺寸由所有素材相对基准的最大范围决定，并增加 2 像素边距，不缩放、不拉伸、不裁掉越界特效。特效变大只扩大公共画布，不单独推移该帧角色。

按从左到右、从上到下播放，速度为每帧 500、250、100、70、50 毫秒，默认 100 毫秒，无限循环。背景默认白色，可选择六位 RGB 颜色，只填充透明区域；「调整方式」「GIF 播放速度」「GIF 背景」统一使用 Medium `ic-segmented-control`，标题在上、选项直接露出并左对齐。调整方式为「特效归属／角色对齐」，速度为「极慢／慢／常速／快／极快」，背景为「纯色／透明」。速度选项悬停显示每帧时长；中英文短标签在 390px 窄屏内完整显示。选择「透明」后隐藏颜色选择器，原透明区域保持透明。预览棋盘格不进入导出文件，切回「纯色」后恢复此前颜色。

GIF 最多 256 色，只支持全透明或不透明。透明输出将 Alpha 小于 128 的像素转为透明，其余像素转为不透明；预留独立透明索引，不会把黑色角色像素误当作透明。每帧结束后清除画面，避免透明区域保留上一帧残影。纯色输出仍将半透明像素与所选背景色合成。

## 状态、失败与限制

原图加载、识别和参数校验完成后才能合成。自动结果及人工调整均检查是否仍有素材跨越归属区域；存在冲突时提示继续微调，角色仍按完整组件输出。没有几何冲突也不能保证特效的语义归属正确。对于交错、缠绕或超出搜索范围的素材，不承诺自动找到无碰撞边界。没有透明背景、没有素材、无法定位所选帧数或角色互相接触时显示双语错误，不退回宫格硬裁剪。截图和带底色的标注图不能代替透明原图。

识别和编码在浏览器 Worker 执行。原图与所有输出帧的总像素分别最多 6400 万，最多 65534 个连通组件；每次处理最多等待 120 秒。关闭弹窗或切换识别参数取消旧请求。编码逐帧处理，不同时持有全部未压缩输出帧。

合成期间禁用设置、取消和重复提交；上传或编码失败保留设置以便重试。取消关闭会放弃本次编辑，刷新页面会放弃未完成的本地任务。

结果复用 `/api/ai/upload` 写入 Managed Media，通过 Canvas Mutation 在来源旁创建 Image Node，沿用保存、下载和撤销。编码前、编码后和上传后检查来源身份；来源删除或替换时不创建结果。不创建 Generation Run 或 Generation History。
