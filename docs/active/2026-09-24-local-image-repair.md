- Status: Implemented — 隔离回归通过；Chrome 真实 Provider 验收发现多结果交付与并发保存缺口，Photoshop 验收待完成
- Date: 2026-09-24
- Tracking: [GitHub #145](https://github.com/lazyq666/reroll-ai-canvas/issues/145)、[LAZ-64](https://linear.app/lazyq/issue/LAZ-64/局部修复功能)

## 目标与边界

Designer 只修改大图的一部分时，可以圈选、裁剪生成，再把修复图贴回原图。原图保持不变，结果节点保存完整合成图及可继续调整的原图、补丁和参数。

使用普通图片编辑能力；圈选用于确定目标包围框及外扩后的矩形裁剪范围，整个裁剪图作为模型输入。提交时根据实际裁剪范围追加目标包围框的百分比坐标，要求只修复范围内缺陷、外围内容仅作参考并保持不变。笔迹不作为模型遮罩，不承诺只有涂抹像素改变，也不承诺具体费用。模型不提供原生遮罩时仍可使用。

Administrator 和获授权 Designer 可以使用；Guest 和匿名分享访问者不能提交、修改或导出。所有服务端操作重新检查画布写权限。

## 交互

1. 图片工具栏原“抠图”位置改为“局部修复”；“抠图”移入“更多”的首项。
2. 在 Image Studio 中选择画笔或矩形，可撤销圈选、清空；焦点在画布时，Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做。选区、提示词与模型选择随来源图片保存。
3. 选区向四周各外扩短边的 35%，至少 32 px，从模型支持的标准画幅中选择能包住区域且面积最小的一项。可切换画幅或重画选区。绿色边框的四边和角点可拖动，围绕中心等比缩放，不得缩小到圈选范围以内；聚焦预览后按 + / − 调整 10%。拖动期间固定坐标投影，结束后适配画幅，超出原图时边框仍可见。重画选区或切换画幅重新计算取景；关闭重开保留手调画幅和分辨率。尽量贴合原图边界；比例无法容纳时，超出原图的部分透明填充。
4. 按裁剪图长边最接近的 1K/2K/4K 等档位默认选择分辨率（K 按 1024 计算），用户可修改。模型与选项以当前 `image.edit` 能力为准。
5. 首次打开优先选择名称或模型 ID 包含 `gpt-image-2.5-suburst` 的模型；其次 `gpt-image-2`，最后首个可用图片编辑模型。已保存的手动选择优先保留。
6. 模型入口复用 Composer 的 `ic-select` 模型菜单（含厂商图标），画幅与分辨率复用 `ic-generation-settings-picker`。支持透明 PNG 的模型显示对应开关，切换到不支持的模型清除开关；选项随草稿和生成记录保留。该开关请求生成透明修复图，贴回时保留其 Alpha，透明区域显示原图；完整合成图不因此移除原图背景。
7. 提示词上方显示手部解剖、手指粘连、多余肢体、AI 涂抹感、衣服褶皱、噪点六项标签。点击替换输入框为预设正文、空行和统一后缀；可继续修改，提交不重复追加后缀。输入框和侧栏保留原生滚动，滚轮不触发外层图片编辑器缩放；移除标签编辑说明和绿色边框说明。
8. 输入修复要求后提交一张裁剪图。输入框上方显示相对裁剪图的修复范围；画笔按包含笔宽的笔迹包围框确定，矩形按框选边界确定，混合或多笔取合并包围框。范围约束由提交时的真实选区与最终裁剪计算，不依赖预设或可编辑公共后缀；以左上角 (0%, 0%)、右下角 (100%, 100%) 描述左、上、右、下边界，要求保留外围上下文和图像布局、输出完整修复图且不绘制标记。用户要求保持可编辑，提交不改写输入框、不重复追加范围约束；重新生成沿用冻结的完整提示词。生成数量复用 Composer 的数量选择器，默认 1 张，上限取当前模型 `image.edit` 数量能力与画布 8 张上限的较小值；切换模型时自动限制到可用数量，选择随草稿保留。同次生成的每张结果放入独立图片节点，并连线到本次操作的直接来源节点；来源本身是已生成结果时也保留这条父子关系。裁剪素材准备完成、前端创建待生成节点后立即关闭局部修复面板，不等待画布同步或服务端任务接收。同步和提交继续在后台执行；生成完成不自动重开。用户从结果节点继续编辑进入调整。素材准备失败保留面板、圈选和提示词；关闭后同步或提交失败保留带错误反馈的结果节点，来源圈选草稿仍可重新打开使用。
9. 生成后按保存的原图像素位置和尺寸贴回。默认边缘羽化为裁剪短边的 6%，参数表示硬度 0% 的柔边擦除画笔直径。画笔沿矩形四条边行进，只擦除边缘窄带；图内影响距离为直径的一半，中心保持原 Alpha。平滑曲线从边缘透明过渡到原透明度，四角叠加擦除；不对整幅图片或颜色进行模糊。直径范围为 0 至修复图短边，0 表示关闭。提供拖动、水平/垂直位置、等比缩放和羽化。重置与原图对比复用 `ic-icon-button` 的 `restore`、`layout-horizontal` 图标、Tooltip 和切换状态；对比沿用 Image Studio 的左右分隔线交互：左侧原图、右侧当前修复预览，默认居中；分隔线可拖动，键盘左右键移动 1%、Shift 加速为 10%，Home/End 到两端。对比不改动修复参数，退出后恢复完整修复预览。不显示文字关闭按钮，沿用 Image Studio 右上角关闭入口。画布获得焦点后，方向键移动 1 px，Shift+方向键移动 10 px。
10. “调整修复结果”只编辑打开时的当前节点，不提供跨结果选择器；确认修改只保存当前结果。要调整其他结果，关闭后从对应画布节点进入。每张结果独立保留位置、缩放与羽化，调整不调用模型。调整草稿随结果图片保存；关闭后可继续调整。确认修改产生新的完整 PNG 并更新结果图片；重复调整始终使用原始补丁，避免多次缩放造成累积损失。“修复另一处”先保存本轮结果，再从合成图开始。
11. 下载 PSD 先同步并保存当前调整，随后导出“原图”和带透明羽化边缘的“修复图”两层。合成预览保持原图尺寸；超出画布的补丁部分裁掉。PSD 不包含可单独编辑的蒙版，也不提供 PSD 回导。

## 局部修复预设设置

首页「设置 → 提示词优化」增加「局部修复」模块。Administrator 可选择六项预设、编辑正文及统一后缀，或恢复当前预设和公共后缀的默认内容；不调用文字模型。切换模块和标签保留未保存内容，保存失败保留草稿。每项正文及后缀最多 6000 个字符，允许后缀留空。

配置沿用工作区的 `data/prompt-optimization.json` 和已有设置接口，V2 增加可选 `repair` 对象，键为 `hand`、`fingers`、`limbs`、`smearing`、`fabric`、`noise`、`suffix`。缺省或 `null` 使用用户提供的内置英文提示词，空字符串保留为空；标签及界面文案提供中英文。默认后缀明确保持未修改元素的空间布局、位置与原图精确对齐，不平移、旋转、缩放、裁切、居中或重新取景。仍保存旧版完整默认后缀的配置在读取时升级到新版默认内容；自定义后缀和空字符串保留。旧配置读取时补默认值，不改写原文件。每次打开局部修复读取已保存配置；读取失败或超过 15 秒时提示并使用默认预设，重新打开可重试，用户仍可手动输入要求。

## 数据与接口

- `images[].local_repair`：版本 2，原图与补丁的 Managed Media 引用、原图宽高、裁剪范围、贴回位置与尺寸、边缘画笔直径；全部使用原图像素。版本 1 保持旧线性羽化解释，避免已有 PNG 和 PSD 无确认改变；打开旧结果编辑时，草稿升级为版本 2，旧羽化距离乘二换算为直径。确认修改后保存新配方和合成图；调整草稿保留 `recipeVersion`，防止重复换算。
- 来源 Node 的 `localRepairDrafts` 保存圈选草稿；结果 Node 的 `localRepairAdjustmentDrafts` 保存尚未确认的调整，仅在对应合成图 URL 未改变时恢复。
- `POST /api/canvas-image-tasks`：可选 `local_repair`；服务端验证托管原图、尺寸、范围、单张输入及模型允许的输出数量。参数冻结在 Generation Run 中。
- 生成交付保存原始补丁及完整 PNG，Canvas、History 和 task result 的 `image_items` 保留修复参数；不会把整张原图作为第二张模型参考图。
- `POST /api/canvases/{canvas_id}/image-repairs/{node_id}/render`：读取已保存素材，接受图片索引、预期 URL、位置尺寸及羽化，可选 `recipe_version: 2` 显式升级蒙版。未提供时保留原版本。成功返回新 PNG 和参数；画布更新走已有 Canvas Mutation。
- 同路径 `/psd`：按已保存的结果状态导出完整 PSD，不修改画布、不生成任务。当前语言下的图层名称随请求传入。
- 原图、裁剪图与补丁按现有 Workspace Managed Media 规则保存和清理；素材引用由现有递归扫描保护，无新增存储目录或迁移。

## 限制、失败与恢复

- 原图、补丁及合成范围最多 4000 万像素，单边最多 30000 px。圈选最多 64 笔、每笔最多 512 个采样点。等比缩放为 25%–200%，上限同时受像素和尺寸限制。
- 无可编辑模型、未圈选或提示词为空时不能生成。素材加载失败显示本地化错误，可关闭后重开重试。
- 生成失败沿用现有失败节点和重试；已接收任务不因关闭编辑器而取消。
- 提交被拒绝时，诊断保留 HTTP 状态及结构化错误码；`repair_invalid`、`repair_source_changed`、`repair_media_missing`、`repair_too_large` 显示中英文原因。未知错误码仍保留，不能收缩为“生成失败”。更新后须重启后端使新配方版本生效；仅刷新页面不能更新后端校验逻辑。
- 保存前后检查当前图片 URL。其他操作替换了结果时拒绝覆盖并提示重新打开；服务端 URL 不匹配返回 409。素材或参数失效返回结构化 422，目标不存在返回 404。
- 保存或同步失败保留本地调整并允许重试；PSD 失败不下载错误响应体。断网后未获同步回执的草稿不保证跨设备或刷新恢复。
- 深浅主题使用共享 Token；中英文切换更新动态标题、提示、字段和图层名称。桌面浏览器是正式目标。
