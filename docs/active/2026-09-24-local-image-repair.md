# 局部修复

- Status: Implemented — 本地验收通过；真实 Provider 与 Photoshop 验收待完成
- Date: 2026-09-24
- Tracking: [GitHub #145](https://github.com/lazyq666/reroll-ai-canvas/issues/145)、[LAZ-64](https://linear.app/lazyq/issue/LAZ-64/局部修复功能)

## 目标与边界

Designer 只修改大图的一部分时，可以圈选、裁剪生成，再把修复图贴回原图。原图保持不变，结果节点保存完整合成图及可继续调整的原图、补丁和参数。

使用普通图片编辑能力；圈选用于确定矩形裁剪范围，虚线框内全部内容都会参与生成。笔迹不作为模型遮罩，不承诺只有涂抹像素改变，也不承诺具体费用。模型不提供原生遮罩时仍可使用。

Administrator 和获授权 Designer 可以使用；Guest 和匿名分享访问者不能提交、修改或导出。所有服务端操作重新检查画布写权限。

## 交互

1. 图片工具栏原“抠图”位置改为“局部修复”；“抠图”移入“更多”的首项。
2. 在 Image Studio 中选择画笔或矩形，可撤销圈选、清空；焦点在画布时，Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做。选区、提示词与模型选择随来源图片保存。
3. 选区外扩短边的 15%，至少 8 px，从模型支持的标准画幅中选择能包住区域且面积最小的一项。可切换画幅或重画选区。尽量贴合原图边界；比例无法容纳时，超出原图的部分透明填充。
4. 按裁剪图长边最接近的 1K/2K/4K 等档位默认选择分辨率（K 按 1024 计算），用户可修改。模型与选项以当前 `image.edit` 能力为准。
5. 首次打开优先选择名称或模型 ID 包含 `gpt-image-2.5-suburst` 的模型；其次 `gpt-image-2`，最后首个可用图片编辑模型。已保存的手动选择优先保留。
6. 输入修复要求后提交一张裁剪图、生成一张修复图。结果放入新的图片节点。生成期间可关闭窗口，后台任务沿用现有刷新恢复流程。
7. 生成后按保存的原图像素位置和尺寸贴回。默认边缘羽化为裁剪短边的 6%；羽化只改变透明度，不模糊颜色。提供拖动、水平/垂直位置、等比缩放、羽化、重置和原图对比。画布获得焦点后，方向键移动 1 px，Shift+方向键移动 10 px。
8. 调整草稿随结果图片保存；关闭后可继续调整。确认修改产生新的完整 PNG 并更新结果图片；重复调整始终使用原始补丁，避免多次缩放造成累积损失。“修复另一处”先保存本轮结果，再从合成图开始。
9. 下载 PSD 先同步并保存当前调整，随后导出“原图”和带透明羽化边缘的“修复图”两层。合成预览保持原图尺寸；超出画布的补丁部分裁掉。PSD 不包含可单独编辑的蒙版，也不提供 PSD 回导。

## 数据与接口

- `images[].local_repair`：版本 1，原图与补丁的 Managed Media 引用、原图宽高、裁剪范围、贴回位置与尺寸、羽化距离；全部使用原图像素。
- 来源 Node 的 `localRepairDrafts` 保存圈选草稿；结果 Node 的 `localRepairAdjustmentDrafts` 保存尚未确认的调整，仅在对应合成图 URL 未改变时恢复。
- `POST /api/canvas-image-tasks`：可选 `local_repair`；服务端验证托管原图、尺寸、范围及单张输入/输出。参数冻结在 Generation Run 中。
- 生成交付保存原始补丁及完整 PNG，Canvas、History 和 task result 的 `image_items` 保留修复参数；不会把整张原图作为第二张模型参考图。
- `POST /api/canvases/{canvas_id}/image-repairs/{node_id}/render`：读取已保存素材，只接受图片索引、预期 URL、位置尺寸及羽化。成功返回新 PNG 和参数；画布更新走已有 Canvas Mutation。
- 同路径 `/psd`：按已保存的结果状态导出完整 PSD，不修改画布、不生成任务。当前语言下的图层名称随请求传入。
- 原图、裁剪图与补丁按现有 Workspace Managed Media 规则保存和清理；素材引用由现有递归扫描保护，无新增存储目录或迁移。

## 限制、失败与恢复

- 原图、补丁及合成范围最多 4000 万像素，单边最多 30000 px。圈选最多 64 笔、每笔最多 512 个采样点。等比缩放为 25%–200%，上限同时受像素和尺寸限制。
- 无可编辑模型、未圈选或提示词为空时不能生成。素材加载失败显示本地化错误，可关闭后重开重试。
- 生成失败沿用现有失败节点和重试；已接收任务不因关闭编辑器而取消。
- 保存前后检查当前图片 URL。其他操作替换了结果时拒绝覆盖并提示重新打开；服务端 URL 不匹配返回 409。素材或参数失效返回结构化 422，目标不存在返回 404。
- 保存或同步失败保留本地调整并允许重试；PSD 失败不下载错误响应体。断网后未获同步回执的草稿不保证跨设备或刷新恢复。
- 深浅主题使用共享 Token；中英文切换更新动态标题、提示、字段和图层名称。桌面浏览器是正式目标。
