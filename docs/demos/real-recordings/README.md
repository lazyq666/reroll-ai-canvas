## 重导出与验证

原始页面捕获暂存在 `/tmp/reroll-live-recordings/<片段>/`，包含 JPEG 和 `frames.json`。临时目录可能由系统清理，交付成片不依赖它。需要再次录制时，使用 Browser 技能控制实际页面，通过真实点击、键盘和拖动操作捕获视口；不要使用旧 HTML 概念动画录制。

在仓库根目录运行：

```sh
python3 docs/demos/real-recordings/export.py
# 也可只重导出一个片段，其他清单条目保留：
python3 docs/demos/real-recordings/export.py --clip quick-tools-short
```

`export.py` 根据时间戳与剪辑表生成成片；`exports/manifest.json` 记录采样、来源、时长与文件大小。成片时长可能与捕获时间戳相差一个编码时间步。

已检查所有 MP4 的 H.264 编码、1600 × 900 尺寸和帧率，以及全部 GIF 的 960 × 540 尺寸和有效帧数；已目视核对分层显隐、角度控制、抠图/深度对比、灯光、账号菜单和库页面。

本批仅增加录屏文件、导出脚本与素材说明，不改变产品行为、领域术语、配置或组件，因此不更新产品 Current 文档。
